# 🩺 Diabetes Prediction System using Machine Learning

## Project Overview
A Machine Learning web application that predicts whether a patient is Diabetic or Non-Diabetic based on their medical information. Built using Python, Scikit-Learn (KNN algorithm), and Gradio for a responsive user interface.

## 🛠️ Technologies Used
* **Machine Learning:** K-Nearest Neighbors (KNN)
* **Web Framework:** Gradio
* **Data Processing:** Pandas, NumPy, Scikit-Learn
* **Deployment:** Render
